# Benchmark di AI Generative per la risoluzione di circuiti di Elettrotecnica

Repository dei dati supplementari e delle evidenze sperimentali relativi alla Tesi di Laurea in Ingegneria Informatica.

L'elaborato valuta le performance di **ChatGPT 5.2 Thinking**, **Gemini 3 Pro** e **Claude Opus 4.5** su 5 casi di studio teorici e 30 casi di studio pratici.

## Contenuto del Repository

### 📂 01_Dataset_e_Link
Questa cartella contiene i dati strutturati per la consultazione e la verifica:

1.  **`Laboratorio_Test.xls`**: Il file master dell'analisi.
    * Include la classificazione degli errori, i filtri per modello/regime e i link diretti alle sessioni di test.
2.  **`Index_Links.xls`**: Un indice rapido contenente esclusivamente i collegamenti alle chat originali per una verifica immediata.

### 📂 02_Evidenze_Sperimentali
Archivio delle prove documentali (screenshot) delle risposte fornite dalle AI.
* Questa sezione funge da **backup statico** e garanzia di autenticità dei risultati, assicurando la disponibilità del dato anche in caso di scadenza o rimozione delle chat dai server dei provider.
* Gli screenshot coprono l'intera campagna di test.
